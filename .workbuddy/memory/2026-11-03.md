## 修复 TLS 证书链不完整问题（AIA 自动补链）
- 根因：cntc.org.cn 服务器只发叶子证书、漏发中间证书 Certum DV TLS G2 R39 CA；Node 不像浏览器那样按 AIA 自动补链。我的测试环境能过是因为 WorkBuddy 注入了 NODE_EXTRA_CA_CERTS（bundle 第58张正是该中间证书），用户终端没有
- 修复：apps/server/src/request/chain-recovery.ts（新）+ http-client.ts 集成：识别 UNABLE_TO_VERIFY_LEAF_SIGNATURE / UNABLE_TO_GET_ISSUER_CERT_LOCALLY / SELF_SIGNED_CERT_IN_CHAIN → 只读 TLS 握手取叶子证书 → 解析 AIA caIssuers URL（手写 DER 扫描）→ 下载中间证书（过 SSRF 校验）→ ca: [内置根+中间证书] 建 Agent 重试一次；按主机缓存（注意 ca 选项会替换默认信任列表，必须合并 tls.rootCertificates）
- 验证：env -u NODE_EXTRA_CA_CERTS 下 HTTP 模式 200（首请求1.5s、缓存后100ms）；365 测试全过（新增 chain-recovery.test.ts 9 个）；规则已切回 HTTP 模式（version 2），栏目测试通过
