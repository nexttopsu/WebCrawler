- `src/shared/crawl.ts`：`ArticleData` 新增 `coverUrl?: string | null`（预留字段，允许为空）。
- `src/core/pipeline.ts`：`cover` / `coverUrl` 纳入标准字段，规则映射时解析为绝对地址；只接受 http(s)，伪协议留空；未映射时 `null`，不猜测首图。
- `src/server/services/article-service.ts`：落库时显式封面优先（相对地址按文章地址补全）→ 回退正文首图 → 都没有则 `NULL`；JSON/CSV 导出补上 `coverUrl`。
- 测试：pipeline 新增封面用例；articles 新增「显式优先 / 回退首图 / 为空」三态用例。`pnpm typecheck` 通过，`vitest run` 375 用例全绿。
- README 补充字段说明与导出说明。

## 站点管理：域名改为从站点地址自动获取

- 前端 `web/src/views/SitesView.vue`：去掉「域名」输入项，站点地址下方实时显示推导出的域名（`derivedDomain`）。
- 后端 `siteCreateSchema` 的 `domain` 改为可选；`common.ts` 新增 `domainFromUrl()`（取 URL 主机名、小写、去尾点，只收 http/https）。
- `createSite` / `updateSite`：只传 `baseUrl` 就自动推导域名；改地址会同步更新域名并做唯一性检查；两个都没给则 400（`details.path = baseUrl`）。显式 `domain` 仍兼容（必须与地址主机名一致）。
- 修复「保存不成功：请求参数校验失败」：前端创建时不再发送 `defaultRuleId`（严格 Schema 不接受创建阶段的默认规则），改为仅更新时提交；`web/src/api/sites.ts` 拆分 `SiteInput` / `SiteUpdateInput`。
- `errorMessage()` 对 `VALIDATION_ERROR` 追加字段级原因（最多 3 条），不再只显示笼统一句话。
- 测试：sites.test 新增「只给地址自动取域名」「改地址域名跟随」「两者都缺报错」；378 用例全绿，`vue-tsc`/`vite build` 通过。
